# Touch-Free Gesture Control Application Using AI Hand Tracking

## 📌 Project Overview
This project focuses on developing a touch-free gesture control application using AI-based hand tracking. The system allows users to control applications and perform actions without physical contact, enhancing hygiene, accessibility, and user experience.

## 🎯 Objectives
- Detect and track hand gestures using AI
- Enable touch-free interaction with the system
- Improve accessibility and usability

## 🛠 Technologies Used
- Python
- OpenCV
- MediaPipe
- Artificial Intelligence / Computer Vision
